## 📖 درباره پروژه

پروژهٔ کامل کافه لوچه در دو بخش جداگانه:

- **فرانت‌اند** (`frontend/`) — سایت عمومی منو به صورت HTML/CSS/JS ساده (راست‌چین و ریسپانسیو) به‌همراه **پنل مدیریت** برای ویرایش منو.
- **بک‌اند** (`backend/`) — REST API با Node.js و Express و MongoDB که دادهٔ منو را در اختیار سایت قرار می‌دهد.

سایت عمومی فقط از درخواست‌های خواندن (GET) استفاده می‌کند و همهٔ عملیات تغییر (افزودن/ویرایش/حذف) با ورود مبتنی بر رمز محافظت می‌شوند.

## ✨ امکانات

### سایت عمومی
- نمایش منو دسته‌بندی‌شده با فیلتر زنده بین دسته‌ها
- لینک اینستاگرام، شماره تماس و موقعیت روی نقشه
- کاملاً راست‌چین، فارسی و ریسپانسیو
- در صورت قطعی سرور، دادهٔ ذخیره‌شدهٔ قبلی نمایش داده می‌شود (fallback)

### پنل مدیریت
- ورود با نام کاربری و رمز (توکن تا یک ماه معتبر)
- افزودن، ویرایش و حذف دسته و محصول
- مخفی‌کردن موقت آیتم‌ها بدون حذف
- مدیریت مدیرها و تغییر رمز
- خروجی JSON و بازنشانی به دادهٔ پیش‌فرض

### API
- دسته‌ها و محصولات با فیلد `hidden` برای مخفی‌سازی موقت
- رمزها با **scrypt** و salt تصادفی هش می‌شوند
- توکن‌های منقضی‌شده به‌صورت خودکار از دیتابیس حذف می‌شوند

## 🚀 راه‌اندازی

### پیش‌نیازها
- Node.js نسخهٔ ۱۸ به بالا
- MongoDB که روی سیستم اجرا باشد (پیش‌فرض پورت ۲۷۰۱۷)

### ۱) بک‌اند (API)

```bash
cd backend
npm install        # نصب پکیج‌ها
npm run seed       # پر کردن دیتابیس با دادهٔ نمونه
npm run dev        # اجرای سرور (با --watch)
```

سرور روی `http://localhost:5000` بالا می‌آید. برای تست سریع، کافی است در مرورگر باز کنید:

- `http://localhost:5000/` — راهنمای endpoint ها
- `http://localhost:5000/api/products` — لیست محصولات
- `http://localhost:5000/api/categories` — لیست دسته‌ها

### ۲) فرانت‌اند (سایت)

فایل `frontend/index.html` را مستقیم در مرورگر باز کنید، یا با یک سرور ساده:

```bash
cd frontend
python3 -m http.server 8080
```

> 💡 آدرس API به‌صورت پیش‌فرض `http://localhost:5000` است؛ اگر سرور را روی پورت دیگری اجرا می‌کنید، آن را در `frontend/js/app.js` و `frontend/js/panel.js` تغییر دهید.

## 🔐 پنل مدیریت

۱. یک کاربر پنل بسازید:

```bash
cd backend
npm run create-user -- A-Man 12345678
```

۲. `frontend/panel.html` را در مرورگر باز کنید و با همان نام کاربری و رمز وارد شوید.

عملیات تغییر (افزودن/ویرایش/حذف) از طریق API نیازمند هدر `Authorization: Bearer <token>` هستند؛ توکن را می‌توانید از `POST /api/login` بگیرید.

## 🔌 مرور API

| Method | مسیر | توضیح | نیازمند توکن |
|---|---|---|---|
| GET | `/api/categories` | لیست دسته‌ها | — |
| GET | `/api/products` | لیست محصولات (فیلتر با `?category=<id>`) | — |
| GET | `/api/products/:id` | جزئیات یک محصول | — |
| POST | `/api/login` | ورود و دریافت توکن | — |
| POST | `/api/categories` | افزودن دسته | ✓ |
| PATCH | `/api/categories/:id` | ویرایش دسته | ✓ |
| DELETE | `/api/categories/:id` | حذف دسته و محصولاتش | ✓ |
| POST | `/api/products` | افزودن محصول | ✓ |
| PATCH | `/api/products/:id` | ویرایش محصول | ✓ |
| DELETE | `/api/products/:id` | حذف محصول | ✓ |
| POST | `/api/users` | ساخت مدیر جدید | ✓ |
| GET | `/api/users` | لیست مدیرها | ✓ |
| PATCH | `/api/users/me/password` | تغییر رمز خود | ✓ |
| PATCH | `/api/users/:username/password` | تغییر رمز توسط مدیر | ✓ |
